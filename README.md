## Pseudocode conventions

- READ accepts input and OUTPUT displays a result.
- IF / ELSE, FOR, and WHILE describe decisions and repetition.
- RETURN gives a result back to the caller.
- Array positions are 0-based unless stated otherwise.
- Graph algorithms use an adjacency matrix and vertices numbered from 0 to V - 1.
