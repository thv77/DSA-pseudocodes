# Algorithm: Linear Search

1. Start.
2. Read the size of the array.
3. Read the element to search (say `k`).
4. Read the array elements using a FOR loop, initializing an index variable using `i = 0`.
5. Begin the search with the element stored in the first position of the array.
6. If the current element is not equal to the key, i.e., `k`, advance to the next position.
7. Continue comparing each element in the array one by one.
8. When the current element matches the key (`k`), stop the search and return the index position of the element.
9. If all the elements have been checked and none matches with the key, report that the element is not found.
10. Stop.
